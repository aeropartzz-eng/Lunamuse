# Catálogo interativo de capacetes

Página simples e interativa, separada do site: filtrar por tamanho, ver o capacete, ampliar a foto no lugar, comprar no site ou no WhatsApp.

- Estilo escolhido: VITRINE (como a vitrine da loja).
- 3D de verdade: modelo rotativo do capacete real, vindo de escaneamento (o Will vai filmar os capacetes); um modelo por modelo de capacete, cores como troca de material.
- Sem pagamento online, sem carrinho.
- Status: página construída pelo Codex Plus, revisada e corrigida pela Luna (ZIP corrigido entregue); falta o GLB (depende do vídeo do Will) e a resposta do Codex Plus sobre print × ZIP.
