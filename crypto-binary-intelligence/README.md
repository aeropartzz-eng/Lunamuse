- Fases 0–13 concluídas e verificadas (617 testes passando). Fases 14–15 travadas esperando o VPS.

- Infra: VPS 4 vCPU / 8 GB, Docker Compose, PostgreSQL/TimescaleDB, Redis, NATS.
- Telegram e WhatsApp em stand-by (painel manual/opcional).
