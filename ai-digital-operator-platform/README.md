# AI Digital Operator Platform

Painel web em português para operar o Galaxy A21s remotamente via agentes de IA, com aprovação humana para ações sensíveis.

- Dispositivo: Galaxy A21s — aguardando conexão (SSH/ADB ainda não entregue).
- Agentes: WhatsApp e Messenger ativos; YouTube e Jogos planejados.
- Janela de resposta de 3 min; checagem a cada 30 min; checagem intensiva (1 min por 5 min) após atividade.
- Deploy: VPS, painel.aeropartz.com.br (DNS A já existe), Caddy + TLS.
- Repo próprio: https://github.com/aeropartzz-eng/Android (brief de deploy + cronograma do A21s lá).
